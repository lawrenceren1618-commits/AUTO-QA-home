# QA sheet contract（templates/点赞、QA.xlsx / sheet `QA`）

服务商原表说明（J1，必须遵守，生成时不要改这格）：

1. Q 或 A 的内容框中不要出现 1.2.3 之类的序号。
2. Q 或 A 的内容框不要出现「问题」或「答案」。
3. 做啥填啥：本流程每行都填提问+回答；不要把分析、标题、类目写进 Q/A。
4. `操作时间` 留空。

## Columns (A–G only)

| 列 | 表头 | 写入 |
|----|------|------|
| A | 序号 | 从当前表已有最大序号 +1 起，全局递增 |
| B | 站点 | 中文站点名（见 language_map），如 `英国` `西班牙` |
| C | Asin（必填） | 大写 ASIN |
| D | 操作时间 | 空 |
| E | 提问内容 | 问句正文 |
| F | 回答内容 | 答句正文 |
| G | 备注 | 短标签，可空 |

禁止写入 H 列及说明区。禁止新增列、改表头、改 sheet 名。

## Forbidden inside E and F

- 行首或句中的列举序号：`1.` `2.` `3.` `1、` `①` `(1)` `1)`
- 字样：`问题` `答案` `Question:` `Answer:` `Q:` `A:` `Pregunta` `Respuesta`（作为标签时）
- 营销前缀：`【QA】` `FAQ:` `Buyers ask`
- 多问一框（一个单元格只能一个问题）
- 把五点/标题原文整段粘贴进回答

## Length (natural, not spammy)

详略得当：像真人在问答区打字，**不要写长。**

| | 建议 | 硬上限（超则改写） |
|--|------|-------------------|
| 提问 E | 一句，约 8–22 词 | 200 字 |
| 回答 F | **1–2 句**，先直接答再补一个可核对细节 | 80 词 / 2 句（第三句仅当必须写边界） |

禁止把五点/A+ 整段搬进回答。不要 “You don’t need to worry”、品牌口号、重复形容词。

问句要像买家：可略口语，不要标题党，不要全是 “Does this…”。
