# Marketplace → sheet 站点 + Q&A language

用户指定语言优先于本表。未指定时用默认语言 **直接撰写**（不要中文稿机翻）。对照稿的中文是释义，不是上架稿。

| marketplace | 站点（写入 B 列） | 默认语言 | 写法要点 |
|-------------|-------------------|----------|----------|
| UK | 英国 | en-GB | colour / organise / towards；问句可用 Have you got / Will this fit |
| US | 美国 | en-US | American spelling。用户明确要西语时，同一 ASIN 可英+美式西语混排，不要每条都做成对照翻译 |
| CA | 加拿大 | en-CA | 默认英式偏美拼；用户要法语再用法语 |
| AU | 澳洲 | en-AU | 英式拼写 |
| ES | 西班牙 | es-ES | ¿…?；tú；不要拉丁美特有词（chévere、vos） |
| MX | 墨西哥 | es-MX | tú； ustedes 仅正式边界场景 |
| DE | 德国 | de-DE | Sie 与 du 混用时偏 Sie（商品问答常见） |
| FR | 法国 | fr-FR | vous 为主 |
| IT | 意大利 | it-IT | Lei / voi 问答体 |
| JP | 日本 | ja-JP | です/ます；不要把英文五点硬译腔留下 |
| IN | 印度 | en-IN | 英语；度量用 listing 原单位 |
| AE | 阿联酋 | en-AE | 默认英语；用户要阿语再 ar |
| BR | 巴西 | pt-BR | 巴西葡语 |

多语言：用户说「英国 + 西语」→ 同一 ASIN 拆两批（如英 20 + 西 15），`marketplace` 仍是实际上架站点。站点是 ES 却写英语 = 服务商会作废。

## Mixing inside one ASIN

允许同一站点下 **一种** 主力语言。不要在同一格中英夹杂（品牌名、型号、单位除外）。
