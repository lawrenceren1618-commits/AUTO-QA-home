# 输出前终审：语法 + 用词

**写完、去重之后，出对照稿 Word / 服务商表之前必须再过一遍。** 这一遍不过，禁止写 docx 或 xlsx。

以对应站点母语来审，不是用中文语感过一遍英文。

## 语法

- 完整句子：主谓齐全。禁止「Same vintage styles, bulk count for…」这类残句
- 冠词 / 单复数 / 时态 / 主谓一致
- 问句要有问号；西语问句要有 ¿ 和？
- 英语不用中式逗号、不用「、」
- 西语名词阴阳性、动词变位；不要英西夹杂（品牌、型号除外）

## 用词

- 像买家在问答区打字，不像标题堆词。同一问句里核心词（如 bud vases）最多自然出现一次
- 答案里禁止再堆 wedding vintage bulk centerpiece
- 禁广告词：best ever、must have、perfect for any、100%
- 禁客服禁令当主句（见避重就轻）
- 介词、搭配要当地习惯：sit firmly on a table，不是 sit solid
- EPE / 喷涂等术语可以留，但句子要读得顺
