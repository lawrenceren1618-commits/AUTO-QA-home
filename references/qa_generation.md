# Phase 2 草稿 + 成稿前覆盖

目的：让没把五点读完的买家，在问答区看到**具体、可核对、带边界**的说明，而不是广告短句。

先写 gist（中文意图），Phase 3 筛完再在 Phase 4 写成目标语言。不要一上来就用英/西语灌 35 条——那样筛查会变成改作文而不是改事实。

## Voice

问句像没读完 listing 的买家；**答句是公正第三方、虚拟热心买家**，不是卖家客服。

- 问句：一个疑点，口语，可带使用情境（garden / kids / sofa / UK plug）
- 答句：先直接答 yes / no / 看情况，再补 **一个** 可核对细节（数字、配件、变体名）。能一句说完就一句。
- 详略得当，符合真实。**不要写太多语句**；禁止三点展开、禁止客服稿。
- 禁止卖家身份：`联系我们` `我们会处理` `Message us` `we'll take care` `contact the seller`。破损可以说 Amazon 退换窗口，不要用「我们」。
- 不要全组同一句式。穿插短问（Does it include a remote?）和带场景的长问
- 不要堆 emoji、星级、Hashtag、品牌口号
- 不要提竞品品牌名

## 撰写者身份

按 [seller_persona.md](seller_persona.md)：对应站点资深运营。QA 问句承接 MCP 里的核心词、场景流量词、长尾高转化词；答案仍是产品事实，禁止堆词。交付时给 listing 十分制（词覆盖 / 场景 / 长尾 / 体验），分数只放说明，不进对照稿、不进单元格。

## 避重就轻（硬规则）

回答先描述 **我们是什么 / 适合怎么用 / 怎么保养**，不要用禁令句当主句。短板可以含在保养或场景里，不要点名「缺点」。

| 不要这样写 | 改成这样 |
|------------|----------|
| 不能进洗碗机 | 活动后凉水手洗即可 |
| 不是水晶，是喷漆会掉 | 染色款是玻璃喷涂上色，色泽统一；透明款是水晶感清玻璃 |
| 把喷涂当主句反复讲 | 工艺提一次即可，主句放玻璃质感、色泽、用法 |
| 喷涂色会更均匀 | 色面比较牢固，软布/细刷轻柔手洗即可；别用强力或带溶剂的清洁剂（不承诺永不掉色） |
| 12/42/84 都是同一只瓶子加量 | 每套都是不同瓶型混搭；件数不同、单瓶大小也略有差别 |
| 回答里写「大约大 20%」 | 只说 12 略大、42/84 略小，不要写百分比 |
| 到货有裂，联系我们 | 泡沫卡位一般能扛运输；若有裂，走 Amazon 退换即可 |
| 向日葵太粗进不去 | 按单枝玫瑰、郁金香这类花茎来用 |
| 大风会吹倒 | 厚玻璃底，适合放在餐桌上 |

**本产品线尺寸（只给撰写者，不要写进问答）：** 42/84 件套单瓶略小，但小得不多；12 件套略大，大得也不多；12 件里最大的大约比 42 件里常见那只大约 20%。问答里只说略大/略小，禁止写 20% 或类似对照数字。不要把三套写成同一组尺寸数字。

**材质：** 透明款按水晶感清玻璃写（扬长）。染色/相近色的核心工艺是喷涂上色，要说，但只点一次，主句仍是玻璃质感、色泽统一、怎么用；不要让客户的注意力停在「喷涂」上。

洗碗机不要单开一条「能不能进洗碗机」。护理问「活动后怎么洗」即可，句中也不必出现 dishwasher / lavavajillas，除非用户点名要写。

## Coverage mix（整批产品默认一共 30–40 条）

按变体需要分配：主推 ASIN 可以占一半以上；颜色/件数专属问题只挂在对应 ASIN。不要每个 ASIN 复制同一套。草稿可略多，筛完压进 30–40。

| 主题 | 条数 | 原料 |
|------|------|------|
| 尺寸 / 适配 / 兼容 | 5–6 | dimensions、评价里的 fit |
| 包装里有什么 / 变体差在哪 | 4 | skuList、features、主图 |
| 材质 / 做工 / 清洗 | 3–4 | features + 评价 |
| 使用场景 | 4 | 类目 + 评价 Layer3 情境 |
| 安装 / 使用步骤疑虑 | 3 | features + 差评里的组装 |
| 保养 / 寿命预期（不保证） | 2–3 | 仅 listing 或评价支持的 |
| 边界 / 微吐槽（降退货） | 6–8 | 1–3★ 与「wish it…」 |
| 隐藏卖点核实 | 3–4 | 五点未强调、评价在夸的 |
| 给谁用 / 礼物 | 2 | 仅当评价或类目有礼物心智 |
| 电源 / 电压 / 保修 | 0–3 | **仅当 listing 写了** |

主题不够就不要凑假规格。超过 40 条（整表合计）删最像广告或最重复的。

## Answer pattern（1–2 句，不要写成 1.2.3）

1. 直接答  
2. 必要时一句细节或边界（数字、配件、变体）。没有第三句除非非写不可。

## Honesty

- listing 没写的：不要答死。宁可不出那条，或答「页面规格以当前尺寸栏为准」且不编数字  
- 评价里的单点吐槽：可以变成「有人反馈…我们建议…」，不要写成「所有人都会坏」  
- 有 A+ 也没正文时：不要说「A+ 第三张图显示…」除非用户给了图

## Self-check before JSON

- [ ] 整批 30–40 条（不是每个 ASIN 30 条）  
- [ ] 语言与站点一致  
- [ ] 每条有站点原文 + 中文释义（`question_zh` / `answer_zh`）
- [ ] 每条 Q/A 过 sheet_contract  
- [ ] 至少 6 条来自评价边界  
- [ ] 数字能在 title/features/overviews/dimensions 或评价中回溯  
- [ ] 无禁用词、无竞品名、无「#1 / 100% / FDA」  
- [ ] 同一 ASIN 问句不重复（近义也算）
