# Phase 3 筛查：像不像真人、是不是真关心、是不是这类目的痛点

三条全过才 Keep。一条 Fail → Rewrite 或 Drop。禁止用「写得通顺」代替证据。

## 1. 真实口吻

Keep：一个疑点、有使用情境、答句用「我们是什么」说完，1–2 句。  
Drop：像广告、像五点复制、卖家客服稿（联系我们、我们会处理）、客服禁令稿（不能进洗碗机、不是水晶）、一条里塞三个问题、回答超过两三句。

## 避重就轻

筛查时若答案主句是「不能/不是/不要」，改写后再 Keep。护理、喷涂、小尺寸都改成描述用法，不改成认错。

## 2. 买家真会在问答区问

问：没把 listing 读完的人，会不会把这句话打进 Ask a question？

| 更会问 | 很少会问 |
|--------|----------|
| 尺寸能不能装进我的 X | 你们品牌故事是什么 |
| 盒里有没有 Y | 为什么选我们（卖点演讲） |
| 能不能淋雨 / 含不含插头 | 值不值得买 |
| 和变体 A 差在哪 | 请给好评 |

没有评价时：只保留 listing 规格能直接挡住退货的问题（尺寸、配件、电压、防水边界）。

## 3. 本词 / 本类目痛点（优化核心）

痛点来源优先级：

1. **评价**（A）：1–3★ + 好评里的 wish/but  
2. **流量词**（B）：`traffic_keyword` / Sif 词表里买家搜索的约束（size、for kids、outdoor、with remote）  
3. **类目常识**（C）：仅当与 1 或 2 同方向。孤立的「这类产品一般会问」→ 最多 3 条，且 answer 不得发明规格

把流量词当成「他们带着什么疑虑来搜」，不要把核心大词本身写成 QA（不要问 What is a pond fountain）。

## 打分（每条 gist）

| 分 | 真实 | 会问 | 痛点 |
|----|------|------|------|
| 2 | 口语、单一疑点 | 退货/适配/缺件类 | 评价或主词里反复出现 |
| 1 | 略书面但可过 | 合理但偏冷 | 仅类目常识且不打架 |
| 0 | 广告腔/多问 | 没人会问 | 无证据或与 listing 相反 |

总分 ≤2 Drop；3 Rewrite；≥4 可进 Phase 4。Keep 集合要覆盖：至少 6 条来自评价边界，至少 4 条来自流量词约束（有词表时）。

## 输出前终审

内容筛查（Phase 3）过了不算完。出对照稿 / 出表前必须再过 [language_pass.md](language_pass.md)：语法 + 用词。堆词、残句、禁令主句，这一遍改掉。

## 知识储备边界

允许：把「户外水泵类常问电压/冬天是否收回」变成 *问题方向*。  
禁止：在 listing 没写电压时答 220V；把别的品牌的配件清单套过来。
