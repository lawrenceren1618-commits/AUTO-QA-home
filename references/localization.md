# Phase 4–5 地区语言与去重

语言跟 **该 ASIN 要上的站点人群**，不是为了显得多国而翻译同一套 QA。成稿同样要短：当地口语 1–2 句，不要把英文长答再译成更长的西语。

## 跟产品挂钩

| 输入 | 语言 |
|------|------|
| 用户指定「英国 / UK」 | 只出 en-GB |
| 用户指定「西班牙 / 墨西哥」 | es-ES 或 es-MX |
| 同一父体要上 UK 和 ES | **两批独立 gist 筛选**，各自用当地语写；不要 EN 定稿再整篇译成西语 |
| 未指定 | 用 marketplace 默认（见 language_map.md） |

「适合地区」以用户给的站点为准，不要用模型猜「这品更该卖欧洲」。若用户要你根据类目建议站点，建议与 QA 生成分开问，QA 仍按已选站点写。

## 当地化（不是翻译）

- 单位：UK 用 listing 原单位，需要时加公分对照，**不要换算错**；换算不了就只保留原单位
- 电源：UK 插头/电压只有 listing 写了才写死
- 称呼：西语 tú（MX/ES 问答区）、德语偏 Sie、法语 vous
- 场景词用当地生活：patio / jardín / Balkon，不要全部 garden
- 禁止中英夹杂（型号、品牌、ASIN 除外）

## 去重

**同语言**：把问句小写、去标点后比较；意思同一适配问题只留证据更强的一条。允许「尺寸」和「能否放进某家具」并存（相近，不相同）。

**跨语言**：若一批里出现两种语言（少见；或 UK+ES 合成表），抽每条 `question_gist`/`intent`：同一 `intent` + 同一 `answer_facts` = 相同 → 删到只留目标站点那条。只是主题同属「尺寸」但问法不同 → 保留。

**错别字**：目标语母语校对一遍；西语开问号、名词性数、英语英式拼写（UK：colour、metre、organise）。
